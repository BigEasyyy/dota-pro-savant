# Dota Pro Savant

Baseball Savant-style stats for Dota 2 pros: xWin, Wins Above Average and percentiles by position,
built from every OpenDota-tracked pro match since The International 2025.

Live site: https://bigeasyyy.github.io/dota-pro-savant/

- `index.html` – the whole site (styles, page and scripts).
- `data/` – the match data and model output, rebuilt every Monday from the OpenDota API.
- `img/` – hero art sheets (hero art and icons © Valve Corporation).

Fan project, not affiliated with Valve or OpenDota.
